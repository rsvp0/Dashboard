# Compartilhamento de convites

Site estático e somente leitura para compartilhar os convites publicados em `rsvp0/Nilda-Sunset`.

Publique o conteúdo desta pasta em uma hospedagem estática com HTTPS para usar o compartilhamento nativo no Android. Não há servidor, conta, banco de dados ou edição do JSON remoto.

O estado de envio fica somente no `localStorage` deste navegador, na chave `nilda-sunset-sharing-state`.
